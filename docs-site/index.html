What happens by itself

These features run in the background after an admin sets them up.

Message logs

Automatic

If a message is edited or deleted, Rob-bot can record that change in the staff log channel. Private channels can be excluded.

Full message text is available only when Message Content is enabled for the bot.

Reputation

Automatic

Rob-bot can give a member +1 reputation for participating, with a limit of once every 10 minutes per person. As people reach the chosen totals, the bot can give them Builder, Contributor, or Mentor roles.

Temporary voice rooms

Automatic

When someone joins the “Create Workspace” voice channel, Rob-bot creates a temporary room for them and moves them into it. The room is removed when it becomes empty.

Scheduled quizzes

Automatic

If staff set a quiz schedule, Rob-bot posts a question at the chosen interval. It waits until the quiz closes before showing the correct answer and explanation.

AI update feed

Automatic

Every 30 minutes, Rob-bot checks the RSS or Atom feeds that staff added. New items are posted to the AI updates channel, and repeat posts are skipped.

Focus timer reminders

Automatic

If a member starts a Pomodoro timer, Rob-bot keeps track of it and posts when the focus session is finished, even if the bot restarted while the timer was running.

Weekly reports and unanswered help

Automatic

Rob-bot can post staff activity summaries and point out build-help threads that have been sitting for more than 24 hours without much activity.

App of the Week

Automatic

Rob-bot can periodically choose an active showcase post that has not been featured before and highlight it in the App of the Week channel. Staff can also choose one manually.

Restart recovery

Automatic

If the host restarts, Rob-bot restores its ticket and quiz buttons, checks temporary voice rooms, resumes timers, and continues scheduled jobs from saved data.

Things people can ask Rob-bot to do

The command names look technical. The actions themselves are simple.

For everyone

Useful community features available to regular members.

/rank or /profile

See a reputation profile and progress.

/leaderboard

See who has the most reputation in the server.

/anonask

Post a question without showing your name publicly. Authorized moderators can still check who sent it if they need to investigate abuse.

/pomodoro

Start, check, or stop a focus timer between 5 and 180 minutes.

/lfg

Post what you are building and what kind of collaborator or help you are looking for.

/solve

In build-help, the thread author can mark a helpful reply as the solution. The helper receives +10 reputation.

For moderators and staff

Tools that need moderation or server-management permissions.

/warn, /timeout, /kick, /ban, /unban

Take moderation action and save a case record.

/history

Review the moderation history saved for a member.

/announce

Write an announcement in a form, preview it privately, then send it when it looks right.

/analytics

See a simple summary of the previous seven days, including moderation, tickets, solved help, quizzes, anonymous questions, and reputation activity.

/app-of-week

Choose a showcase thread to feature manually.

/anonwho

For authorized moderators only: check the sender of an anonymous question when there is a legitimate moderation reason.

For ticket and content setup

Normally used only when configuring or maintaining the server.

/ticket-type add

Create a ticket option such as “Support”, “Partnership”, or “Report a problem”.

/ticket-panel post

Post the button members use to open a ticket.

/quiz add, /quiz start, /quiz schedule

Add quiz questions, post one immediately, or set the automatic schedule.

/ai-source add

Add an official RSS or Atom feed that Rob-bot should watch for new AI updates.

/reputation thresholds

Change how much reputation someone needs before they receive Builder, Contributor, or Mentor.

For server configuration

These commands tell Rob-bot where things are in Discord.

/setup text-channel

Choose a text channel for something such as logs, announcements, analytics, or AI updates.

/setup voice-channel

Choose the Create Workspace or Coworking Lounge voice channel.

/setup forum, /setup category, /setup role

Tell Rob-bot which forum, category, and reputation roles to use.

/setup feature

Turn a Rob-bot feature on or off for this server.

/setup status

Check what has been configured and what is still missing.

Admin setup guide

Set it up once, then let the team use it.

Setup progress

Tick each item after you have tested it. This checklist is saved only in your browser.

0 of 10 complete

Install Rob-bot in the Discord server

In the Discord Developer Portal, install the app with the bot and applications.commands scopes. Give it only the permissions it needs. Administrator is not required.

Turn on Message Content if you want full logging

Leave Presence Intent and Server Members Intent off. Turn Message Content Intent on if you want deleted/edited message text, richer ticket transcripts, solution excerpts, and message-based reputation context.

Add the hosting settings

On the bot host, add your Discord token as a secret, set the environment to production, and add your Discord server ID as COMMAND_GUILD_ID. You can leave the database setting empty to use the built-in SQLite database.

Do not share the token.

The bot token is effectively the bot’s password. Keep it in the hosting provider’s secret/environment-variable area.

Create the Discord channels, forums, categories, and roles

Create the places Rob-bot will use: logs, tickets, announcements, AI updates, build help, showcase, voice rooms, and the Builder / Contributor / Mentor roles.

Tell Rob-bot where those things are

Use the /setup commands to connect each Discord channel, role, forum, category, and the Solved tag. Finish with /setup status to see anything still missing.

Set up tickets

Add the ticket types your team wants, post the ticket panel, then open a test ticket. Make sure staff can see it, regular members cannot see other people’s tickets, and a closed ticket produces a transcript.

Set up reputation and build-help

Connect the Builder, Contributor, and Mentor roles. The default milestones are 50, 150, and 500 reputation. Then test marking a build-help reply as solved.

Add at least one quiz

Add a quiz question, start it manually, and check that answers are recorded. If you want regular quizzes, set a schedule after the manual test works.

Add AI sources and test the community tools

Add only RSS/Atom feeds your team trusts. Test a feed poll, an anonymous question, a Pomodoro timer, an LFG post, and the temporary voice-room flow.

Review privacy and switch off anything you do not want

Exclude private staff channels from message logging, use /setup feature to disable unused systems, then run /ping and /setup status as a final check.

If something is not working

Check the simple things first.

The slash commands do not appear.

Make sure the app was installed with applications.commands, the correct server ID is in COMMAND_GUILD_ID, and command syncing is enabled. Restart the bot after changing those settings.

A moderation command says Rob-bot cannot act on someone.

Discord role order matters. Move the Rob-bot role above the member or role it needs to moderate, and make sure the matching moderation permission is enabled.

Reputation roles are not being assigned.

Check that Builder, Contributor, and Mentor were connected with /setup role. Rob-bot also needs Manage Roles, and its own role must sit above the roles it gives out.

Edited or deleted messages show no text.

Turn on Message Content Intent in the Discord Developer Portal and set ENABLE_MESSAGE_CONTENT=true on the host. Without that, the bot can still run, but Discord may not provide the full message text.

Everyone can see a ticket.

Fix the permissions on the ticket category: deny @everyone View Channel, then allow only the staff roles that should handle tickets.

AI updates are not appearing.

Check that the AI updates channel is connected, background tasks are enabled, and the feed is active. Staff can run /ai-source poll to test it immediately.

What happens if the bot host restarts?

Most state is saved. Rob-bot re-runs database migrations, restores persistent ticket and quiz controls, checks temporary voice rooms, and resumes scheduled work from saved timestamps and sessions.

Admin-only technical reference

You can ignore this section unless you manage the Discord app or hosting.

Discord intents

Presence Intent: off. Server Members Intent: off. Message Content Intent: on if you want full message text, richer ticket transcripts, solution excerpts, and message-based reputation context.

Recommended bot permissions

View Channels, Send Messages, Send Messages in Threads, Embed Links, Attach Files, Read Message History, Manage Channels, Manage Threads, Manage Roles, Move Members, Moderate Members, Kick Members, and Ban Members. Administrator is not required.

Hosting environment variables

DISCORD_TOKEN is required and should be stored as a secret. Recommended values: ENVIRONMENT=production, COMMAND_GUILD_ID=<your server ID>, ENABLE_MESSAGE_CONTENT=true when the Discord intent is enabled, ENABLE_BACKGROUND_TASKS=true, and SYNC_COMMANDS=true. Leave DATABASE_URL unset to use SQLite at data/marwie.db.

Database and backups

SQLite is enough to start. The bot creates and migrates the database automatically. Keep host backups enabled. PostgreSQL can be added later by setting DATABASE_URL.
