Permissions

Check hierarchy first when moderation or role management fails.

  1. 1Server OwnerHighest. Cannot be moderated.
  2. 2Admin / LeadershipOptional protected layer.
  3. 3Rob-botAbove members it moderates and roles it manages.
  4. 4Moderator / SupportDay-to-day staff.
  5. 5MentorReputation ≥ 500.
  6. 6ContributorReputation ≥ 150.
  7. 7BuilderReputation ≥ 50.
  8. 8Member rolesCommunity and interest roles.
  9. 9@everyoneBase role.

Rob-bot

  • View Channels, Send Messages, Embed Links, Attach Files, Read Message History
  • Manage Channels, Manage Threads, Manage Roles, Move Members
  • Moderate Members, Kick Members, Ban Members

Moderators

  • Moderate Members — /warn, /timeout, /history, /anonwho
  • Kick Members — /kick
  • Ban Members — /ban, /unban
  • Manage Threads — mark another member's build-help reply solved
Hierarchy

The moderator and Rob-bot must both outrank the target. The server owner cannot be targeted.

Resources

Discovery first

Use manual /setup … commands only for overrides. Auto-setup never deletes, renames, moves, or merges resources.

Ticket privacy

Deny @everyone View Channel on the ticket category; allow only ticket staff. Rob-bot adds the opener.
