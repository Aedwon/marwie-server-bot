# Decision: hierarchy before containers

Date: 2026-08-26

## Decision

The handbook and command manual will share one visual refinement layer whose default is hierarchy through typography, spacing, tonal contrast, and composition—not visible component borders.

Card-like surfaces may use a quiet fill and restrained radius when grouping is useful. Borders are reserved for structural separators such as table rows, long lists, and state boundaries. Repeated outlined cards, pills, and nested boxes are explicitly avoided.

The handbook Start area becomes a task launcher: concise outcomes and workflow cues in one composed surface instead of four independent paragraph cards.

The command manual retains the scan-first disclosure model, but command entries become soft filled rows/cards without outline framing. Workflow paths become inline operational sequences instead of callout boxes.

## Consequences

- The two pages read as one product.
- More information can remain visible without making the site feel dense or document-like.
- Important callouts still receive tonal emphasis, but they do not introduce another border system.
- Existing accessibility semantics, source content, anchors, search, and responsive behavior remain unchanged.
