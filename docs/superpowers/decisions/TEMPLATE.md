# Decision log template

Date: YYYY-MM-DD
Topic: ...
Status: accepted / superseded

## Context

What needed a decision? Keep this tied to behavior, data, security, operations, or architecture.

## Options considered

### Option A

What it does and what it costs.

### Option B

What it does and what it costs.

Add more options only when they were genuinely considered.

## Decision

State the choice plainly.

## Reason

Record the facts that changed the decision. Keep this useful to a future agent who would otherwise reopen the same question.

## Consequences

What does this choice require or rule out?

## Later changes

Append dated reversals or amendments here. Do not delete the original decision.
