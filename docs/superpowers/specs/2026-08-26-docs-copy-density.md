# Operator homepage copy density

Date: 2026-08-26
Status: accepted

## Goal

Make the Rob-bot operator homepage faster to scan for moderators and administrators without removing operational meaning.

## Rules

- Prefer one precise word over a phrase when meaning is preserved.
- Remove kicker labels that repeat the section heading.
- Remove UI instructions the interface already makes obvious (for example, “Choose your task” or “Open …”).
- Keep safety-critical permissions, hierarchy, privacy, confirmation, and setup behavior explicit.
- Keep the exhaustive command manual unchanged; the homepage is the concise operating index.
- Preserve the existing information architecture and links.
- Avoid marketing language and conversational filler.
